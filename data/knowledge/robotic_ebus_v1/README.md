# Launch contract 0.2.0 / robotic_ebus_v1

`launch_dictionary.json` maps the updated source workbook to the focused launch contract. It includes 176 contract fields, five existing application context bindings, the full clinical JSON Schema and 999 source fields retained for the roadmap. Original source definitions are preserved beside explicit launch adaptations.

The profile is diagnostic robotic bronchoscopy and linear EBUS only. Other procedure modules remain in development. The JSON and review workbook are engineering contract artifacts; clinical field/measure and independent release qualifications remain pending.

`reviewed_eval_selection.json` is the small, source-reviewed synthetic pilot described in [the implementation report](../../../docs/ROBOTIC_EBUS_LAUNCH_IMPLEMENTATION.md). It is not a complete clinical or independent evaluation dataset.
